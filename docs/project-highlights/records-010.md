## D14 · Windows退出时closed pipe二次异常

- 日期/执行者/状态：2026-10-13，用户提供BaseSubprocessTransport与Proactor析构堆栈，AI临时子进程复现并修复；Windows本地验收通过。
- 分级：M/F/D/U=1/0/2/0，3分L1。单adapter生命周期逻辑；本故障首次反馈，无独立追问；退出/管道/取消启动交互，根因高置信；未称大难题。
- 影响：结束或问答失败后，子进程通信资源未清完，析构期间repr访问已关闭句柄产生ValueError，掩盖真正的模型400；不等于JSON检查点丢失。
- 根因与复现：local_embedding.aclose只在returncode为空时kill+wait；已退出且还有未读缓冲时不清理，wait也不保证stdout已EOF。临时真实子进程填满输出后kill，修复前adapter关闭后stdout.at_eof=false，测试失败；另一取消/超时案例初跑通过，失败观察也保留于忽略日志pipe-repro.log。3.10堆栈来源与CPython本机实现复核对应，不编造系统损坏。
- 实施：关闭stdin，允许退出/kill竞争的ProcessLookupError，communicate排空管道并等stdin.wait_closed，进程已退出也清理；外部aclose与encode共锁，内部异常清理不重复取锁；启动过程shield并在取消后接管实际子进程再清理，避免孤儿。未加依赖，未调用付费模型。
- 尝试与验证：三项真实子进程测试覆盖已退出但未排空、超时/取消、启动中取消，分别在开发Python3.12和用户agent环境Python3.10.21通过。3.10首次测试因asyncio.TimeoutError与builtin TimeoutError类型不同失败，调整测试断言为asyncio.TimeoutError后通过，不掩盖测试结果。实际已安装本地MiniLM仅编码合成文本，384维、child_exited=true、stdout_eof=true、transport_closed=true、unraisable_errors=[]；运行脚本在忽略目录local-pipe-smoke.py，未发送用户文章或调用模型服务。完整279项通过，报告同上；未恢复原会话。
- 作用/限制/简历：增加Windows本地embedding worker确定性退出、异常与取消清理，避免已退出进程遗留未清理管道；可说明异步子进程生命周期回归能力。未测试强制结束整个解释器或所有反复取消竞态，不声称覆盖全部平台故障，也不混入问答质量成果。

## D15 · Rich 推理展示层级

- 日期/执行者：2026-10-13，用户反馈推理 Markdown 显示问题；AI 定位、实现与离线验证。

- 问题/根因：用户确认“助手问题”指推理/思考。现有 on_reasoning 已调用 MarkdownRenderer，但与最终回答共用默认样式，没有灰色层级；不能据此断言服务返回的推理曾丢失。
- 尝试1：AI 增加真实 hook→Rich→ANSI 解析回归，覆盖标题、强调、链接、列表、表格和代码。初次测试因测试传入 None console 报错，修正后断言无颜色失败，复现缺少灰色。
- 方案/实施：renderer 增加 muted 参数；Rich 完成 Markdown 排版及高亮后，对每段覆盖灰色并清除特殊背景，保留强调/链接信息。实时推理标题与内容启用 muted，最终回答维持原路径。glow/auto 的 muted 内容经 Rich，plain/依赖缺失回退原文；不改模型请求、状态或推理提取协议。
- 尝试2：初轮修复验证仍失败，观察执行环境 NO_COLOR=1；测试独立启用颜色，保留生产 NO_COLOR 行为。Windows legacy 将灰色244降级到标准色8；测试先因 Color 对象名称不同失败，改为核验解析色号244/8，最终18项展示/推理测试通过。
- 验收：18项展示/推理专项通过；首轮统一284项仅灰色测试因Windows色号断言失败（报告 `code/eval_results/20261013T073633211003Z/report.md`），修正测试后统一284项0失败/错误/跳过（`code/eval_results/20261013T073917033723Z/report.md`）。改动diff空白检查及全部台账卷容量检查通过；未调用付费模型、未读取用户文章或修改用户会话。
