## 已实现：作品集网站辅助亮点

### W1. 全栈作品与内容管理

- **实现**：Next.js App Router + Prisma/SQLite；后台 session 守卫、文章/作品 CRUD、发布状态控制、Markdown 预览、图片上传转 WebP；Server Actions 写入前验证管理员身份，保存后按路径刷新公开内容。
- **改善**：把作品、技术文章维护与公开展示形成闭环；预览复用公开渲染组件，减少两套渲染逻辑的维护差异。
- **证据**：网站 `src/lib/auth.ts`、`src/app/admin/(protected)/posts/actions.ts`、`projects/actions.ts`、`src/components/admin/markdown-editor.tsx`、`src/app/api/upload/route.ts`；网站 `docs/TASKS.md` M1/M2/M5 历史验收。
- **限制**：网站已有单篇中译英 Action，但它是网站自身能力，不是 Blog-Agent 管理/发布链路；Agent 与网站尚未联通。
- **简历表述**：构建 Next.js 全栈作品集网站，完成作品/文章管理、鉴权写入、Markdown 统一预览和图片处理，作为 Agent 项目及技术成果的展示载体。

### W2. 部署与数据运维

- **实现**：多阶段 Docker、standalone、Caddy、启动迁移、SQLite 在线备份及上传文件配对备份；运维文档覆盖更新、回滚和恢复。
- **改善**：提供可重复部署及数据恢复路径，支持持续维护作品集内容。
- **证据**：网站 `Dockerfile`、`docker-compose.yml`、`Caddyfile`、`scripts/backup.sh`、`docs/OPS.md`；M4/M5 记录了本地恢复演练与 2026-07-17 站主确认上线。
- **限制**：本轮未复测公网或恢复演练；不宣称高可用、零停机或大规模生产运维。
- **简历表述**：通过 Docker 与 Caddy 部署作品集网站，配置数据库迁移、在线备份和图片备份，编写更新、回滚及恢复流程。

### W3. 交互动效与状态竞态修复

- **实现**：GSAP 滚动/页面动效及 reduced-motion 降级；当前首页在水面补间期间阻止反向手势触发松锁，并依据 observer 启用状态重新锁定滚动。
- **改善**：视觉展示具备运动降级；首页修复将交互锁状态与场景完成状态解耦，处理反向切换中的滚动卡死路径。
- **证据**：网站 `src/components/motion/`、`src/components/home/home-hero.tsx` 的 animW/onDown/onUp/isEnabled 分支；本条首页修复仅本轮静态核对，未做新的浏览器复测。
- **限制**：部分视觉能力仍在 Lab；不把实验场景写成首页已上线能力。M3-10 的 Lighthouse 94–98 是 2026-07-09 旧版测试，当前首页已改，不作为当前性能成绩。
- **简历表述**：使用 GSAP 实现作品展示与滚动交互并支持 reduced-motion，处理场景反向切换中的滚动锁竞态，改善交互状态恢复逻辑。
